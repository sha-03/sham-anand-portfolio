# Sham Anand Portfolio

Personal portfolio website featuring UI/UX work, AI/ML projects, interactive animations, credentials and contact information.

## Overview

A dependency-free, responsive portfolio for Sham Anand. It combines editorial monochrome design with original motion, Web Audio interactions, an interactive avatar, project demos and an accessible contact experience.

## Features

- Home, About, Projects, Credentials and Contact sections
- Five interactive AI/ML project case studies
- Right-side desktop navigation and mobile navigation
- Original page transitions: CARD, INK, CURTAIN, SPIRAL and RISE
- Interactive 3D character, custom cursor, micro-interactions and synthesized sound
- Responsive, keyboard-accessible design with reduced-motion support

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript and Web Audio API

## Structure

```text
index.html
assets/css/       Stylesheets
assets/js/        Application JavaScript
assets/images/    Portfolio imagery and certificate previews
assets/videos/    Motion video assets
assets/models/    Notes for browser-side model assets
assets/icons/     Notes for inline icon assets
assets/sounds/    Notes for synthesized sound
docs/             Project documentation
```

## Local development

Open `index.html` in a browser, or serve the repository root with any static-file server. No build step or package installation is needed.

## Deployment

The site is deployed with GitHub Pages from the `main` branch and repository root.

Live website: https://sha-03.github.io/sham-anand-portfolio/
