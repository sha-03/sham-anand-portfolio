# Project notes

This is a dependency-free static site built for GitHub Pages. All links are relative to the repository root, so the portfolio works without localhost, a bundler or server-side code.

- Visual assets are organized under `assets/images`.
- Motion video assets are organized under `assets/videos`.
- The interactive digit model is embedded directly in `assets/js/app.js`.
- Icons are inline SVG and sounds are original Web Audio synthesis, so no external icon or sound files are required.
- Credential years and external credential URLs remain intentionally editable placeholders in `assets/js/app.js`.
